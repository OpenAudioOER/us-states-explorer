## 💡 How It Works
1. When a student clicks **"Click to Listen 🔊"**, the app automatically looks for `/audio/{STATE_ID}.mp3` (e.g. `/audio/NC.mp3`).
2. If the `.mp3` file exists, it plays your recorded audio!
3. If an `.mp3` file is missing, the app automatically falls back to clear text-to-speech so questions never get stuck!
